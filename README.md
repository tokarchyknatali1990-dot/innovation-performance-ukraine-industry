Аналіз результативності інноваційної діяльності підприємств України за обсягом реалізованої інноваційної продукції, 2015–2025 рр.

##📊 Опис проєкту
Цей проєкт присвячений аналізу ефективності інноваційної діяльності промислових підприємств України. Досліджуються тенденції, динаміка змін у часі та регіональні відмінності.

## 🎯 Мета проєкту
Оцінити динаміку та регіональні відмінності інноваційної активності підприємств України за показником обсягу реалізованої інноваційної продукції у 2015–2025 рр.

## 📁 Дані та матеріали
- Аналітичний звіт (Word документ)
- Розрахунки та структурований аналіз

## 📈 Основні висновки
- Спостерігається динаміка змін інноваційної активності у часі
- Є суттєві відмінності між регіонами
- Загальна тенденція розвитку інноваційної діяльності в промисловості
