# Аналіз результативності інноваційної діяльності промислових підприємств України за обсягом реалізованої інноваційної продукції (2015–2025)

## 📊 Опис проєкту
Цей проєкт присвячений аналізу результативності інноваційної діяльності промислових підприємств України за показником обсягу реалізованої інноваційної продукції у період 2015–2025 років. Досліджуються динаміка змін у часі та регіональні особливості інноваційної активності.

## 🎯 Мета проєкту
- Оцінити результативність інноваційної діяльності промислових підприємств України  
- Проаналізувати динаміку обсягу реалізованої інноваційної продукції  
- Виявити регіональні відмінності  
- Сформувати інсайти для прийняття управлінських рішень  

## ⚙️ Обробка даних
Дані були отримані та оброблені з використанням BigQuery. Після обробки сформовано фінальний датасет для подальшого аналізу.

## 📁 Дані та файли
- **Work.xls** — оброблений датасет, експортований з BigQuery (підготовлені дані для аналізу)
- **innovation-analysis.docx** — детальний аналітичний звіт з описом підходу, розрахунків та інтерпретацією результатів

## 📈 Основні висновки
- Спостерігається значна нерівномірність інноваційної результативності між регіонами України  
- Динаміка показує зміни обсягів реалізованої інноваційної продукції у часі (2015–2025)  
- Існують регіони з стабільно високою та низькою інноваційною активністю  
- Загальна тенденція свідчить про структурні відмінності в розвитку інноваційної економіки  

## 🛠 Використані інструменти
- BigQuery — обробка та підготовка даних  
- Excel — фінальний датасет (Work.xls)  
- Tableau Public — візуалізація дашборду
